Engagement éthique : protection des élèves et respect de la vie privée

La Suite EdNum est conçue pour être utilisée dans les écoles primaires et secondaires, sur des tablettes et des ordinateurs scolaires ou personnels. Parce que nos utilisateurs sont principalement des enfants et des adolescent·e·s, nous appliquons le principe fondamental de minimisation absolue des données : aucune donnée personnelle n’est jamais demandée, collectée, analysée ou vendue.

1. Absence totale de collecte de données personnelles

L'utilisation de la Suite EdNum garantit une totale sérénité aux équipes éducatives et aux familles :

  • Aucun compte utilisateur : Aucune inscription, adresse e-mail, identifiant ou mot de passe n'est requis pour utiliser les applications.
  • Aucun cookie traceur : Nous n'utilisons aucun cookie tiers, traceur publicitaire ou outil de profilage marketing.
  • Aucune télémétrie externe : Aucun outil d'analyse comportementale (type Google Analytics ou pixels de tracking) n'est injecté dans les pages.
  • Aucun tiers commercial : Aucune régie publicitaire n'est présente sur la plateforme. Les outils sont 100% sans publicité.

2. Données sauvegardées localement

Afin d'offrir une progression adaptative et de sauvegarder les réussites des élèves, les applications sauvegardent certaines informations techniques exclusivement sur votre appareil via l'API standard localStorage de votre navigateur :

  • Scores et records : Niveaux franchis, étoiles obtenues, séries de victoires et meilleurs temps réalisés lors des exercices.
  • Préférences d'affichage : Thème visuel choisi (clair, sombre, contraste élevé) et état du son (activé / muet).
  • Configuration d'outils : Listes d'élèves saisies localement pour le Tirage au sort ou barèmes paramétrés dans le Générateur de barème.

Ces données ne quittent jamais votre machine : elles ne sont jamais transmises à un serveur, ni partagées entre différents appareils.

3. Partage par URL

Certaines applications (notamment le Simulateur Automate) permettent aux enseignant·e·s de configurer un parcours, une grille ou un défi et de le partager avec leurs élèves via un simple lien web ou un QR code :

  • Encodage exclusif dans l'URL : Les paramètres de configuration du jeu (type de tapis, obstacles, position de départ) sont encodés en texte clair ou compacté directement dans la chaîne d'adresse (dans l'ancre # ou les paramètres ?config=).
  • Zéro transmission serveur : Aucune donnée de défi n'est envoyée, traitée ni enregistrée sur nos serveurs. Le partage s'opère de manière strictement décentralisée et directe entre l'émetteur et le récepteur.

4. Effacement des données

Dans la mesure où aucune donnée nominative ou profil d'élève n'est collecté par nos soins, la gestion et l'effacement des données relèvent du contrôle total de l'utilisateur.
Vous pouvez à tout moment purger l'ensemble des données de progression enregistrées sur votre appareil en cliquant sur le bouton « Réinitialiser les scores » présent dans les paramètres du portail, ou en vidant les données de navigation dans les préférences de votre navigateur.

6. Autonomie totale et mode hors-ligne (PWA)

La Suite EdNum est développée comme une Progressive Web App (PWA) autonome :

  • Fonctionnement sans connexion : Une fois installée ou chargée une première fois, l'ensemble des ressources (code, images, polices, sons) est conservé dans le cache local du navigateur via un Service Worker.
  • Écoles sans connexion internet : Les élèves et les classes peuvent ainsi travailler de manière 100% autonome en mode déconnecté, sans qu'aucune requête réseau ne transite vers l'extérieur.
