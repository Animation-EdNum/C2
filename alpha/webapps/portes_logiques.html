5 missions interactives pour maîtriser les circuits logiques
Mission 1 : La porte NON (La veilleuse automatique)
Défi 1 / 5
Un capteur de luminosité émet 1 en plein jour et 0 dans l'obscurité. La veilleuse automatique doit s'allumer UNIQUEMENT quand il fait nuit (capteur = 0) !
🎯 Objectif : Active les interrupteurs pour faire briller la lampe et teste toutes les combinaisons de la table de vérité. Combinaisons : 0 / 2
🎉 Félicitations ! Tu as percé le secret de ce circuit logique !
Choisir le circuit :
Schéma de câblage réactif Signal actif : 1 (Courant ON)
Entrées : 0 + 0 Addition binaire = 0 02 Valeur décimale = 0
Table de vérité Clique sur une ligne pour l'activer

Le langage binaire : Dans un circuit, l'information circule sous forme de tension électrique. 0 représente l'absence de tension (0 Volt, éteint) et 1 représente une tension active (5 Volts, allumé).

Les transistors : À l'intérieur d'une puce ou d'un processeur, des milliards de minuscules interrupteurs microscopiques appelés transistors s'associent pour former ces portes logiques.

Le Demi-Additionneur : En combinant une porte XOR (pour calculer la somme) et une porte ET (pour détecter la retenue), un ordinateur est capable de calculer mécaniquement l'addition $1 + 1 = 2$ ($10_2$) ! C'est la base absolue de toutes les calculatrices et consoles de jeu.
