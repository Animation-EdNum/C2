# 🧠 Mode d'emploi : IA & Machine Learning

Les applications **Dresseur de neurones** et **Détective IA** initient les élèves à l'intelligence artificielle de façon visuelle et interactive : comment une machine apprend à partir de données, et pourquoi elle peut se tromper.

---

## Pourquoi ces outils ?

- **Démystifier l'IA :** Une intelligence artificielle ne « pense » pas — elle applique des calculs statistiques sur des exemples qu'on lui a fournis.
- **Apprentissage supervisé :** Découvrir le cycle : *Entraîner → Ajuster → Tester*.
- **Biais algorithmiques :** Constater qu'une IA entraînée sur des données incomplètes ou stéréotypées produit des décisions biaisées.

---

## 1. Dresseur de neurones

L'élève entraîne un **neurone artificiel** (perceptron) pour trier automatiquement des éléments (pommes vs bananes, ou formes géométriques) selon leurs caractéristiques.

### Déroulement

1. **Constituer le jeu d'apprentissage :** L'élève étiquette manuellement un échantillon (« ceci est une pomme », « ceci est une banane »).
2. **Entraîner le neurone :** Ajuster les poids synaptiques (importance de chaque critère : couleur, taille, rondeur) pour déplacer la frontière de décision.
3. **Tester :** De nouveaux éléments inconnus sont présentés. L'IA les classe-t-elle correctement ?
4. **Découvrir le biais :** Si l'élève n'a montré que des pommes rouges et des bananes jaunes, que se passe-t-il avec une pomme verte ? → Discussion sur le biais des données d'entraînement.

---

## 2. Détective IA

L'élève se met dans la peau d'un **détective numérique** qui analyse les décisions d'algorithmes d'IA :
- Pourquoi le système a-t-il commis une erreur ?
- Comment corriger les données ou les paramètres pour améliorer ses prédictions ?

Ce mode développe l'esprit critique face aux systèmes automatisés.
